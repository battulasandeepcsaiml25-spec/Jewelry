# Sahira Jewelry Design - Exact 1:1 Website Clone

This directory contains the exact, authentic 1:1 production copy of **[Sahira Jewelry Design](https://sahirajewelrydesign.com/)**.

## 📁 Files in This Workspace

* **`index.html`**: The exact production homepage structure containing all original sections, product items, navigation menus, mega-menu dropdowns, slideshow carousels, customer reviews, and footer markup.
* **`theme.css`**: The complete production theme stylesheet (Prestige theme).
* **`sahira-custom.css`**: Sahira's custom typography, spacing, and component overrides.
* **`depict-gpt-search.css`**: Search overlay and product modal styling.
* **`accelerated-checkout-backwards-compat.css`**: Mobile wallet & accelerated checkout styles.
* **`vendor.min.js`**: Core animation, touch, and carousel libraries.
* **`theme.js`**: Full custom-element theme engine initializing all 95 Shopify web components (`<x-header>`, `<slideshow-carousel>`, `<cart-drawer>`, etc.).
* **`logo.svg`**: The official Sahira Jewelry Design brand logomark.

## 🚀 How to Open and Preview

### Option 1: Direct File Opening
Simply double-click **`index.html`** or right-click &rarr; **Open with** &rarr; **Google Chrome** (or Microsoft Edge).

### Option 2: Local HTTP Server (Recommended for full web-component features)
In PowerShell or terminal inside this folder:

```powershell
python -m http.server 8000
```

Then open your browser at:
`http://localhost:8000`
